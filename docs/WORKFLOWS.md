# 从仪器档案到科研数据复核

## 1. 登记网关和仪器

设备管理先登记实际网关，再关联仪器。网关通信方式、厂家、固件和超时属于共享网关；仪器单位、位置与数据时效属于仪器。修改一台仪器不能改动共享网关配置。

没有通信证据时网关保持待接入；没有自己的有效记录时仪器保持无数据。登记不会生成在线事件。已有仪器的编号、类型和网关绑定不能直接覆盖；本次安装履历处理的是试验小区迁移，不是物理网关换接。

## 2. 仪器详情与指标档案

点击设备名称进入详情，集中查看网关状态、仪器状态、各指标最近有效值、有效值来源、最近异常报文、协议档案、告警及安装履历。

在“新增档案版本”填写版本、协议名称、解析程序版本、校准记录、依据，并逐项定义代码、单位和语义（待核实/瞬时/累计/时段）。可设必需指标与独立有效期；未知资料不补造。档案不可更新或删除，修改需新增版本。最新档案用于当前指标要求和时效检查；内部适配器仍须明确指定本次解析的 `profileId`，不会自动假定最新文档已经通过硬件验证。

每份原始报文保留实际使用档案的快照，旧测量语义不随新版本改变。详情同时区分有效值采用的版本和当前时效配置。最近解码无效时，页面保留上一次有效值但明确提示异常，并分别链接两份原文。

## 3. 建立试验、小区和安装履历

在试验管理依次建立试验、小区与处理，再选择实际仪器和明确安装时间。同一仪器的安装时段不能重叠。迁移时结束旧安装记录，在结束时刻或之后建立新记录。旧记录不能覆盖。

区间包含开始、不包含结束。测量按设备采集时间归属，刚收到的补传记录仍归当时小区。设备时间缺失时保持未归属，登记时间和接收时间不充当测量时间。试验和小区登记本身不产生测量。

## 4. 查询、统计与导出

实时监测、历史和分析共享 URL 查询条件：仪器、指标、单位、时间口径、起止、排序、试验及小区。先选择再查询；切换页面保留条件。小区选项与试验联动，避免选择互相矛盾的归属。

- 服务器接收时间查询可包含设备时钟缺失的可信记录，含义是“何时收到”。
- 设备采集时间查询只包含存在有效采集时间的记录，绝不混入接收时间回退值。
- 表单按浏览器本地时区输入，API/导出保留带时区时间并标准化用于筛选；查询上下界包含边界。安装归属另按半开区间判断。
- 历史每页 25 条，监测/图表最多 500 条；页面显示匹配总数和当前显示数。图表不插值，不将离散记录解释为连续采样。
- 完整范围统计由数据库对全部匹配有效记录计算，不受分页/图表上限影响。展示数量、最小/最大读数；只有全部记录明确为瞬时值时计算逐条算术均值。它不是时间加权均值。
- 累计/时段/未知语义不计算均值或派生累计量。日降雨、清零差分、溢出补偿仍待实机定义。
- 质量排除计数仅覆盖同范围内已解码的测量；无法解码的报文到诊断查看。采集时间筛选下的缺失设备时间计数是所选系列全部时间的提示，不声称它们属于选定采集时段。

CSV 包含原始 ID、时间/质量、档案快照、试验小区和查询时间口径。JSON 包含完整行、筛选条件、统计方法、生成时间和行数据 SHA-256，可保存为复核材料。两种导出都限制最多 50000 条，超过时提示缩小范围且留在原查询页面。校验值只能检测内容变化，不证明仪器数据真实性。不同时间的导出可能因新数据或新增安装档案而不同，应保存当次 JSON。

## 5. 从异常到处理和恢复

告警源于已经发生的通信、数据过期或解析/测量异常。服务每 30 秒评估，打开告警页也评估；同一活动条件不重复生成告警。未接入、从未有数据或超时未配置不制造离线/过期事实。

处理路径：总览需要关注 → 仪器详情 → 原始证据 → 告警确认/备注 → 新证据满足恢复条件。确认只说明已记录处理，故障依然存在。修改超时、更新兄弟指标或重新投递旧观测都不能替代发生异常指标的新观测。网关恢复需要新的有效通信事件。

处置时间线保留触发、确认、备注、恢复及证据引用；操作审计可在系统设置查看。`local_operator` 仅表示未认证的本机操作来源。当前不提供测量阈值规则编辑、外部通知或远程控制。

## 6. 空状态、错误和测试

空库有登记入口，无有效指标有接收诊断入口，请求失败有明确错误和重试。没有数据不会填 0 或生成曲线。具体软件验收见 [TESTING.md](TESTING.md)，真实设备能力与公网安全仍按 [HARDWARE_PROTOCOLS.md](HARDWARE_PROTOCOLS.md)、[SECURE_INGESTION.md](SECURE_INGESTION.md) 核实。
