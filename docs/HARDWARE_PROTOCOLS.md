# 硬件与协议核实

项目暂以用户指定的 D100L-Ym2 命名，实际完整型号、铭牌和固件版本待现场核对。LanSense `backend/src/modules/device-ingest/routes.js` 的注释提及 D100L2-Ym2 的 HTTP 主动上报；这不是本项目设备铭牌或全部固件能力的证明。银尔达 [YED-D100L2-Y 产品页](https://www.yinerda.com/productinfo/5915459.html) 提及 MQTT，但不能据此认定 D100L-Ym2 是同一型号或支持相同能力。

以下各项对本项目实际设备均待说明书、固件版本及实机核实：MQTT 客户端、协议版本、QoS 1、自动重连、TLS、自定义 Topic、JSON、Modbus RTU 主站轮询、连续寄存器读取、本地缓存和断网补传、远程修改通信参数。

水位计、电磁流量计、雨量计的型号及各自波特率、数据位、停止位、校验位、从站地址、通信协议、寄存器地址、数据类型、字节序、倍率、单位和刷新周期均待核实。RS485 只表明物理接口，不能据此推定 Modbus RTU。三类仪器须分别确认协议，不借用水位计寄存器定义。

如实际 DTU 不能直接发布 MQTT，应评估独立协议转换网关或平台侧接收适配器，并验证鉴权、可靠性、离线补传和时间来源后再选择；当前不接入硬件、不发送控制命令。
