## DTU

型号：YED-D100L2-Ym2。据提供的说明书摘要：一路 RS485，1200–230400 baud、7/8 数据位、1/2 停止位、奇/偶/无校验，支持 0–20 mA 模拟电流输入；透传固件支持 TCP、UDP、MQTT、HTTP、WebSocket 等。现场固件、MQTT 配置、协议版本、QoS、TLS、重连、主题、JSON、轮询、缓存及补传能力仍须核实，不能推定现场设备已使用 MQTT。LanSense `backend/src/modules/device-ingest/routes.js` 注释提到 D100L2-Ym2 HTTP 主动上报，但不能证明本项目设备的实际配置。

## 雨量计

山东塞恩电子科技有限公司 SN-YL-N01-3002；资料摘要称 Modbus RTU、8 数据位、无校验、1 停止位、出厂 4800 baud，默认从站地址 01，支持 2400/4800/9600 baud；使用功能码 03H 读取 0000H 雨量寄存器，整数除以 10，分辨率可选 0.2 mm 或 0.5 mm。实际设备分辨率和现场参数未核实。厂家完整通信示例尚未获得，不得以自造测试帧冒充厂家示例。不得向设备发送清零、修改地址或波特率命令。

## 水位计

采购资料仅称压力式、量程 0–1 m、精度要求 ≤0.1%FS、温度补偿、RS485。厂家、型号、协议和寄存器未确认；不实现具体寄存器解析。

## 流量计

采购资料涉及小区电磁/超声波及主渠道电磁流量计，部分配置 RS485；具体厂家、型号、协议、寄存器和单位未确认，不得套用其他厂家寄存器。

接入层预留 HTTP、MQTT 或 TCP 的适配空间；实际方式取决于现场固件、透传格式及仪器说明书。现阶段不连接设备，不发送控制指令。
