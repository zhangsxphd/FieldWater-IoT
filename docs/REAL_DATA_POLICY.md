# 真实数据政策

正式平台只接收实际仪器数据；设备须由用户登记，禁止自动生成设备或测量记录。禁止使用随机数据、默认监测值、静态演示数据或虚构告警填充正式界面。无数据时使用空状态，未接入设备不得仅因没有上报而判为离线。

每条数据保留可追溯来源及原始报文，设备时间与服务器接收时间分开记录；解析失败的报文仍须保存并记录原因。派生指标必须有明确计算方法和原始数据来源，不确定时不计算。

厂家示例和测试报文仅用于隔离的协议测试或临时测试数据库，不得写入生产数据库或作为实测数据显示。接入前核实仪器型号、协议和 DTU 配置，不对真实设备发送控制命令。

## 授权的本地演示

从独立演示命令启动的服务只打开 `:memory:`，忽略 `FIELDWATER_DB`。演示数据使用预设样本、独立标识和场景时钟。监测、试验归属和告警均通过现有计算流程产生。演示页面持续显示来源，导出文件保留演示标记。正式服务没有演练样本入口，打开演示链接不会改动业务库。
