# 测试与本地验收

本阶段验收日期：2026-11-13。测试为隔离算法/数据库/浏览器测试，不是实机通信或厂家样例认证。

## 自动化命令

`npm test --prefix backend`：15 项测试实际通过，包括空库、网关独立登记、多传感器状态、超时、通信异常、原文保留、解析失败、未经验证来源、重复/冲突、设备时间、数据质量、筛选先于分页、跨站写保护、迁移保留、CSV 和非法日期。

`npm run build --prefix frontend`：Vite 生产构建实际通过。

`npm run test:e2e --prefix frontend`：使用本机 Google Chrome，通过 Playwright 实际执行界面流程。脚本 `tests/ui-workflow.cjs` 在系统临时目录新建数据库，启动独立测试后端和前端；端口被占用则立即拒绝执行。测试完毕关闭服务并删除自己创建的临时目录。

浏览器覆盖：

- 空库总览、空在线率和下一步入口。
- 登记网关、同网关登记两台仪器、修改仪器不出现网关通信配置。
- 只有 A 有可信测试记录：A fresh、B no_data。
- 按仪器和指标查询、分析结果、测量链接到原文。
- 拒绝来源的原始记录可查，不能进入正常分析。
- 八个路由、390×844 手机宽度无横向溢出、接口错误提示、没有页面 JS 异常。

在 1440×960 桌面视口另做了截图检查：导航、统计标签、空状态下一步、表单入口、质量详情与数据语义均核对。沿用绿色/蓝色视觉体系；有意以网关/仪器双层统计取代旧“设备在线”概念，以操作入口取代无依据的数值和曲线。内置浏览器此前启动超时，本阶段使用本机 Chrome/Playwright。

## 测试数据隔离

所有测试设备名、报文及数值都是标记为 `isolated-test` 的独立测试向量。没有设备模拟器、演示模式或正式库种子。用户操作页面不自动生成任何设备或测量。
